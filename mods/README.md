# Downloadable content

`packsync.jar` is the stable-file-name build used by server URL sync.

It is the same jar as `build/libs/packsync-1.0.0.jar`, copied here so it can be
served from GitHub Raw:

```
https://raw.githubusercontent.com/WBlackTL/ZhanchengSync/main/mods/packsync.jar
```

Keep the file name stable when publishing a new build, otherwise clients will
end up with both the old and new jar in `mods/`.
